# demo

Media for the project demo, kept together so the README and wiki can reference a
single place.

| File | What it is |
|---|---|
| `demo.gif` | The safe-remediation loop end to end: investigate with free reads, propose a change, get rejected by the guardrails and correct it, wait for a human-signed token, apply, verify, and report from the audit log. Shown at the top of the [README](../README.md), above "Why this exists". |
| `demo.mp4` | Full walkthrough recording (added after recording). |

The end-to-end **test** report is separate: it is generated by
[`hack/e2e-local.sh`](../hack/e2e-local.sh) and published to the wiki as
[Test Results](https://github.com/sandeepbazar/ocm-mcp-server/wiki/Test-Results).
