# Code of Conduct

ocm-mcp-server is committed to a welcoming, harassment-free community for everyone,
regardless of background or experience level.

This project adopts the
[CNCF Community Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md),
which is based on the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. Adopting the CNCF Code of Conduct keeps this project aligned with the wider
cloud native community as it works toward CNCF Sandbox consideration.

## In short

Be respectful. Be constructive. Assume good intent. Keep the space welcoming.
Harassment, personal attacks, and sustained disruption are not tolerated, in any project
space (issues, pull requests, discussions, and any associated channels).

## Reporting

To report unacceptable behavior, contact the maintainers privately by connecting on
[LinkedIn](https://www.linkedin.com/in/sandeepbazar/). All reports are handled
confidentially and reviewed promptly. Reporters will not face retaliation.

For incidents involving the wider cloud native community, the
[CNCF Code of Conduct Committee](https://www.cncf.io/conduct/committee/) can also be
contacted per the CNCF process.
